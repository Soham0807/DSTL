Practical 6 — Create Dashboard in Tableau / Power BI

Goal:

Year-wise sales
Location-wise sales
Interactive filters
TABLEAU DASHBOARD
Step 1 — Create Required Charts

Create:

Sales by Year
Sales by Location
Category-wise Sales

Each in separate sheets.

Step 2 — Create Dashboard

Click:

Dashboard → New Dashboard
Step 3 — Drag Sheets

Drag all sheets into dashboard.

Resize properly.

Step 4 — Add Filters

Click chart dropdown:

Use as Filter

Now clicking a city updates all charts.

Example

Click:

Mumbai

Dashboard shows only Mumbai sales.

Viva Questions
What is interactive dashboard?

Dashboard where charts respond dynamically to filters/user actions.

Why use filters?

To analyse specific data subsets.
