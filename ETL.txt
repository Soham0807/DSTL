IMPORTANT VIVA QUESTIONS
What is ETL?

ETL stands for Extract, Transform, and Load.

What is Power Query?

Tool in Power BI used for data cleaning and transformation.

What is Merge Query?

Used to combine two tables using common columns.

Why use custom columns?

To create calculated fields from existing data.

What is line_total?

Total amount calculated using:

UnitPrice × Quantity
Difference between Load and Transform?
Load	Transform
Imports data	Modifies data
COMMON ERRORS
ERROR 1 — Cannot expand table

Cause:

Wrong table selected.

Fix:

Ensure:

OrderID

selected in both tables.

ERROR 2 — Formula error in custom column

Fix:

Use exact field names shown after expansion.

Example:

[UnitPrice] * [Quantity]

instead of prefixed names if prefix removed.

ERROR 3 — Blank chart

Fix:

Ensure numeric field placed in:

Values
