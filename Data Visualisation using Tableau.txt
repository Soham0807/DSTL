Practical: Data Visualization Using Power BI
Aim

To perform data visualization using Power BI by:

Connecting sales dataset
Creating Line Chart
Creating Bar Chart
Creating Treemap
Analyzing insights from data

using Power BI Desktop
.

STEP 1 — Open Power BI
Launch Power BI Desktop
Click Get Data

Choose:

Excel / CSV

Select your sales dataset.

Click:

Load
STEP 2 — Verify Dataset

Your dataset contains columns like:

Product
Region
OrderDate
Quantity
TotalPrice
CustomerType
STEP 3 — Create Total Sales Measure

Right click Sheet1 → New Measure

Paste:

Total Sales = SUM(Sheet1[TotalPrice])

Press ✔️

STEP 4 — Create Bar Chart
Purpose

Compare sales across regions/products.

Steps
Click empty report area
In Visualizations → select Clustered Bar Chart

Drag:

Axis → Region
Values → Total Sales
Insight from Bar Chart
Region with highest sales can be identified.
Region with lowest sales can be analyzed.
STEP 5 — Create Line Chart
Purpose

Analyze sales trend over time.

Create Year Column

Right click Sheet1 → New Column

Year = YEAR(Sheet1[OrderDate])

Press ✔️

Create Line Chart
Select Line Chart

Drag:

Axis → Year
Values → Total Sales
Insight from Line Chart
Sales growth over years can be observed.
Highest performing year can be identified.
STEP 6 — Create Treemap
Purpose

Visualize contribution of products/categories.

Steps
Select Treemap visual

Drag:

Group → Product
Values → Total Sales
Insight from Treemap
Products with highest contribution occupy larger area.
Helps identify best-selling products.
STEP 7 — Add Filters (Optional)
Add Slicer
Select Slicer visual

Drag:

Region
OR
Year

Now dashboard becomes interactive.

STEP 8 — Format Visuals

Go to:

Format Visual

Enable:

Titles
Data labels
Borders
Background

Rename charts:

“Sales by Region”
“Year-wise Sales Trend”
“Product Contribution”
Expected Output

Dashboard containing:

Bar Chart
Line Chart
Treemap
Interactive filter
Conclusion

Successfully connected sales dataset and created multiple visualizations like bar chart, line chart, and treemap in Power BI to gain business insights.
