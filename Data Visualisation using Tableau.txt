Sheet 1

Understanding Tableau Interface

You’ll see:

Section	Purpose
Rows	Y-axis
Columns	X-axis
Marks	Color/labels
Show Me	Chart suggestions
Data Pane	Dataset columns
a. Create Line Chart

Visualize sales over time.

Steps

Drag:

Order Date

to:

Columns

Then drag:

Sales

to:

Rows

Now click:

Show Me → Line Chart

Sales increase during festive seasons.
b. Create Bar Chart

Drag:

Category

to Columns.

Drag:

Sales

to Rows.

Choose:

Show Me → Bar Chart
Insight Example

c. Create Tree Map

Drag:

Category

and:

Sales

Choose:

VIVA QUESTIONS
What is Tableau?

A data visualization tool used for interactive dashboards and analysis.

What is a dashboard?

Collection of charts and visuals in one screen.

What is a dimension?

Categorical data like city/category.

What is a measure?

Numerical data like sales/profit.
