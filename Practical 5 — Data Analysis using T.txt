Practical 5 — Data Analysis using Tableau / Power BI

Goal:

Use aggregate functions:

SUM
AVG
COUNT
MAX
MIN
STDDEV
VAR
COVAR
CORR
TABLEAU METHOD
Step 1 — Load Dataset

Same as previous practical.

Step 2 — SUM of Sales

Drag:

Sales

to Text.

By default Tableau shows:

SUM(Sales)
Step 3 — AVG

Right click Sales:

Measure → Average
Step 4 — MAX/MIN

Right click:

Measure → Maximum

or

Minimum
Step 5 — COUNT

Drag any column like:

Order ID

then choose:

Measure → Count
Step 6 — Standard Deviation

Create Calculated Field:

Analysis → Create Calculated Field

Name:

STDDEV

Formula:

STDEV([Sales])
Step 7 — Variance

Formula:

VAR([Sales])
Step 8 — Correlation

Calculated field:

CORR([Sales],[Profit])
Step 9 — Covariance
COVAR([Sales],[Profit])
